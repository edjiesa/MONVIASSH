Alat Investigasi & Pembersihan Kapasitas Disk (Linux POSIX)

Klik perintah apa saja untuk menyalin langsung ke clipboard

1. 10 Folder Terbesar
du -sh /* | sort -hr | head -10

Cari folder pemakan space terbesar di root.

2. Bersihkan Log Systemd
journalctl --vacuum-size=200M

Batasi ukuran journal log ke max 200MB.

3. Bersihkan Docker
docker system prune -af

Hapus image dangling & container mati.

4. Bersihkan Cache Paket
apt-get clean || yum clean all

Hapus cache file instalasi apt/yum.
