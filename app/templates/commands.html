Lihat Semua Proses PostgreSQL

Menampilkan seluruh background worker, master daemon, dan client backend connection aktif.

Monitoring
ps -ef | grep postgres

Hitung Jumlah Koneksi / Proses PostgreSQL

Menghitung total session atau background process PostgreSQL yang sedang aktif.

Count / Statistik
ps -ef | grep postgres | wc -l

Kill Proses Autovacuum

Menghentikan worker autovacuum yang sedang berjalan saat membebani resource CPU / disk I/O tinggi.

Kill Worker
ps -ef|grep autovacuum|grep -v grep|awk '{print $2}'|xargs kill
Versi aman tanpa error jika tidak ada proses:

Kill Proses Transaksi (trans)

Menghentikan koneksi PostgreSQL yang statusnya transaksi aktif atau menggantung (idle in transaction).

Kill Transaction
ps -ef|grep trans|grep -v grep|awk '{print $2}'|xargs kill
Versi aman tanpa error jika tidak ada proses:

Kill Query SELECT yang Menggantung

Menghentikan query pembacaan data `SELECT` yang macet atau membebani database terlalu lama.

Kill Query
ps -ef|grep SELECT|grep -v grep|awk '{print $2}'|xargs kill
Versi aman tanpa error jika tidak ada proses:

Kill Proses MIS

Menghentikan seluruh session atau background process yang berkaitan dengan aplikasi / job `mis`.

Kill App Job
ps -ef|grep mis|grep -v grep|awk '{print $2}'|xargs kill
Versi aman tanpa error jika tidak ada proses:

Kill Proses Idle PostgreSQL

Menghentikan koneksi client PostgreSQL yang sedang dalam keadaan `idle`.

Kill Idle
ps -ef | grep postgres | grep idle | grep -v grep | awk '{print $2}' | xargs -r kill
